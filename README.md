# Smart Classroom Energy Management System

## 📌 Project Overview

The **Smart Classroom Energy Management System** is a project designed to support energy monitoring and efficient energy usage in classroom environments. It combines software-based monitoring and computer vision concepts to support smarter classroom energy management.

The project repository includes frontend and backend components, hardware-related resources, research documentation, and YOLO-based model files.

## 🎯 Objectives

- Promote efficient energy usage in classrooms.
- Explore automation for smarter classroom management.
- Integrate software components with hardware-related resources.
- Explore computer vision using YOLO models.
- Support the development of a smart and energy-conscious learning environment.

## ✨ Project Components

- **Frontend:** Contains the user interface and web-related files.
- **Backend:** Contains backend-related files and database connection code.
- **Hardware Part:** Contains hardware-related project resources.
- **Research Part:** Contains research documents and supporting material.
- **YOLO Model:** Contains Python scripts and YOLO model files for computer vision-related functionality.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/shwetashinde-05/smart-classroom-energy-management-system-.git
```

### 2. Open the Project Folder

```bash
cd smart-classroom-energy-management-system-
```

### 3. Set Up the Backend

Ensure Node.js is installed. Open the `Backend` folder and install the dependencies listed in `package.json`.

```bash
cd Backend
npm install
```

### 4. Configure the Database

Review `connectdb.js` and configure the database connection using the appropriate local settings. Do not publish database passwords, API keys, or other credentials.

### 5. Run the Project

Follow the instructions in the backend scripts and project documentation to start the application. Open the frontend HTML file in a browser if it can run independently.

*The exact run commands depend on the scripts and configuration included in the repository.*
